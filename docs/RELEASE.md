Hollyhock 3 Custom Launcher 0.5 für OS 02.01.7002.0001.

- Fünf zuletzt gestartete Apps oben in der Liste; die letzte App ist vorausgewählt.
- Weniger Dateizugriffe beim Laden der Programminfos.
- SDK als festgesetztes Submodule, automatische Tests und reproduzierbar gepinnte Toolchain.

die Test-App, Anleitung, Prüfsummen, Testberichte und den vollständigen Quellcode
einschließlich SDK unter `source/`. Ein Firmwareupdate ist nicht nötig.

Die automatisierten Prüfungen bestehen. Der abschließende Test am echten ClassPad
steht noch aus, einschließlich dauerhafter MCS-Speicherung und realer Ladezeiten.
