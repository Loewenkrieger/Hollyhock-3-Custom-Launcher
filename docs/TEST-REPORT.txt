Hollyhock 3 Custom Launcher 0.5 - test report

Scope
-----
HH3 launcher for installed Hollyhock 3 on OS 02.01.7002.0001.
Hardware testing: NOT performed. No complete Casio OS emulation is claimed.

Launcher behavior
-----------------
The launcher discovers and loads HH3 apps from the calculator root directory.
The classic interface handles touch events and physical keys directly.
The checked return adapter returns Cancel (0x03eb) to the OS 7002 caller at
0x8015c898 and resumes the normal path at 0x8015cf94. A different caller
signature retains the native completion dialog; errors remain explicit.

Automated checks: 36 passed
---------------------------
UI: 21 controller/renderer checks and 4 real gui.cpp adapter checks, using
ASan and UBSan. LeakSanitizer is disabled because hosted environments may
block its inspection of /proc threads.
Discovery: 3 checks against production app_list.cpp and the actual file
search template; OS enumeration is mocked and ELF execution is replaced
by assertion stubs. Checks cover mixed formats, unsupported-only files,
sorting, hidden files and directories. No app is loaded or executed.
Exit: 6 tests of the actual exit-result factory and native fallback under
UBSan. The real-address ROM probe conflicts with ASan shadow memory.
Target: 2 narrow SH instruction-consumer checks use the actual return
object and callback from the linked target image. They reach the normal
OS continuation; the old null-return regression faults at address 0x4c.
This limited interpreter does not simulate the rest of the calculator.

Repository cleanup validation: 2026-10-29
-----------------------------------------
All 34 host checks and both target-consumer checks passed again.
The target-consumer checks used the distributed ELF and raw binary;
host nm output was normalized for the SH leading-underscore convention.
The executable, retained launcher/SDK sources, smoke app and previews
are unchanged. No fresh calculator build was performed for this cleanup.

Build and distribution checks
-----------------------------
SuperH big-endian ELF32; machine EM_SH; entry 0x8cfd0000.
The image remains within the reserved launcher RAM.
The linked ELF contains only the HH3 app loader.
The bundled HH3 SDK and HH3 smoke app build with the pinned toolchain.
The archives are checked for CRC, matching binary hashes and absence of
unsupported app-loader sources and firmware/updater files.
Renderer previews are generated by the production renderer on the host.
